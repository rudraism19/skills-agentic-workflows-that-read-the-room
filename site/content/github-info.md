## Latest GitHub Updates

### Stacked pull requests are generally available

GitHub stacked pull requests are now generally available, making it easier to break a large change into smaller, independently reviewable pull requests that can be merged together.

Source: https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/ — October 6, 2026

### Copilot code review adds API support and a new default effort level

GitHub Copilot code review can now be requested through the REST and GraphQL APIs, and the review effort level can be configured for each request. Balanced is now the default effort level.

Source: https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level/ — October 2, 2026

### GitHub Copilot can interact with desktop apps with computer use

Computer use is available in public preview in GitHub Copilot CLI and the Copilot app on macOS and Windows, allowing Copilot to interact with desktop applications on a user's behalf.

Source: https://github.blog/changelog/2026-10-01-github-copilot-can-now-interact-with-desktop-apps-with-computer-use/ — October 1, 2026
